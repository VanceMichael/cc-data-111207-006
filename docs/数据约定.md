# 数据约定

value 顺序定义同一窗口内的操作顺序，version 为门店级递增整数。普通对象是补丁，removed=true 是删除；未出现字段与 null 不等价。nextLink 表示窗口尚未完成，deltaLink 是完成后的后续入口，二者不同时出现。

nextLink 只在单个未完成窗口内检测回环。完成的空增量可原样返回输入 deltaLink，这不代表异常，下一次同步仍使用该链接。

链接是不透明值，连接器只按原样跟随，不解析或重组其中的页号。同源相对链接与同源绝对链接都可用；跳转到其他源站的链接视为越界并拒绝。跨越两个窗口不继承 `nextLink` 的已访问记录，从上一个窗口 `deltaLink` 起算的新窗口可以复用某个链接字符串。

版本比较针对门店最近一次已知版本，包括已删除门店留下的版本记录，因此删除后以更低版本重开会记为版本倒退。同版本且内容一致的重放视为幂等；同版本但内容不同、或版本倒退的操作只记录冲突，不改写当前值。

410 表示增量游标过期，连接器丢弃该游标并从全量重新开始。新全量完整走到 `deltaLink` 之前，正式视图保持上一版可读；新全量完成后才切换，并从这里返回的 `deltaLink` 继续下一次增量。旧窗口的暂存进度与游标在新窗口开始时一并清除，不跨重启复用。
